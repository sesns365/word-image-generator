# 語詞圖片生成 skill（word-image-generator）

給教師、講師、教材設計者與家長使用的 Claude skill。輸入語詞，就會為每個語詞各產生一張 1:1、純白背景、適合教材與圖卡的圖片。

由特工365 製作。

## 功能

- **一般模式**：只輸入語詞。具體物品（如蘋果、地瓜葉）用寫實攝影風格；抽象概念、情緒、動作（如合作、等待、生氣）用簡潔教育插畫，可加繁體中文對話泡泡。
- **文本模式**：貼上課文、故事或社會故事，再指定語詞。所有圖片會沿用文本中的人物外觀、場景與同一種畫風，讓整組圖卡風格一致。
- 一個語詞一張圖，順序與輸入一致，不漏圖、不重複，一次最多 10 個語詞。
- 圖中不會直接寫出目標語詞，方便做配對與命名練習。

## 安裝

1. 點本頁上方綠色的「Code」按鈕，選「Download ZIP」，解壓縮。
2. 找到裡面的 `word-image-generator` 資料夾（內含 `SKILL.md`），把這個資料夾單獨壓縮成 zip。
3. 在 Claude 的「設定 → 功能（Capabilities）→ Skills」上傳這個 zip。

Claude Code 使用者可直接把 `word-image-generator` 資料夾放到 `~/.claude/skills/`。

## 使用範例

一般模式：

```
幫我生成語詞圖片：合作、分享、等待、地瓜葉、蘋果
```

文本模式：

```
文本：
小明和小美放學後一起到公園。小美帶了一盒彩色筆，小明想畫畫，小美就把彩色筆借給他……

語詞：分享、彩色筆、開心
```

## 注意事項

- Claude 本身沒有內建生圖功能。若你的環境接有生圖工具，skill 會直接出圖；沒有的話，會依序輸出每個語詞的中英文生圖提示詞，可貼到其他生圖工具使用。
- 本 skill 供成人製作教材使用，請勿輸入學生姓名、照片等個人資料。
